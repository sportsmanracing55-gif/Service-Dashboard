One row per advisor, with a header row. Copy straight from Excel or Google Sheets. Column names are matched loosely, so Labour Gross, Lab Gross Sales and Gross all work. Unrecognised columns are ignored.

Either wide (Date, then one column per advisor, optional Total) or long (Date, Advisor, Count). Dates can be 01/09/2026, 2026-09-01 or 1 Sep. Pasting replaces any existing rows for the same dates.

Optional overrides for department figures. Leave a value blank to use the total calculated from the advisor table. Paste as Label → Value lines, or a two-row header/value table.
